# Hot Wire Styrofoam Cutter
## The Problem
Nichrome wire is a nickle-chromium alloy which heats up when a current is run through it and is commonly used in everyday appliances such as toasters and hair dryers. I, along with my other engineering students - [Nathan Turner](https://nathant-cell.github.io/eng2_portfolio/) and [Justin Cassidy]() - were charged with using this wire to create two styrofoam cutters which could be used to build sets for the drama department. The first styrofoam cutter was to sit on a table or the ground so styrofoam could be run through it and cut in straight lines. The second was to be a handheld one which could carve out pieces of styrofoam. Both had to be wired to connect to a power source to heat the wire.
